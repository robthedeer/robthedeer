### 🚀 What I'm Building Now

I'm currently developing **[FundiAI](https://github.com/yourusername/fundi-ai)** — an **offline-first, AI-powered educational platform** designed for low-resource classrooms in Southern Africa. It uses quantized LLMs running on edge devices (Raspberry Pi) with a RAG pipeline to deliver curriculum-aligned, vernacular learning without requiring constant internet connectivity.

**Why this matters:** 89% of learners in Sub-Saharan Africa lack home computer access. FundiAI turns a single solar-powered device into a personal AI tutor, democratizing STEM education in the last mile.
